# Uber Eats Bangalore Restaurant Analysis

## Project Overview
This project analyzes Uber Eats Bangalore restaurant data to provide business insights and support decision-making for restaurant owners, customers, and food delivery platforms.


## Technologies Used
- Python
- Pandas
- SQLite
- SQL
- Streamlit
- Git & GitHub
