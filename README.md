# Uber Eats Bangalore Restaurant Analysis

## Project Overview
This project analyzes Uber Eats Bangalore restaurant data to provide business insights and support decision-making for restaurant owners, customers, and food delivery platforms.


## Technologies Used
- Python
- Pandas
- SQLite
- SQL
- Streamlit
- Git & GitHub


## To get the Streamlit Visualization
- Streamlit_vis.py has to be used

- ## Files
- Streamlit_vis.py – Streamlit application for visualization
- Uber Eats Bangalore Restaurant Intelligence and decision support system – Guide given 
- Uber_Eats_data.csv- data set given 
- orders.json -  Data set given
- extract_frm_file.ipynb - Data cleaning of csv file
- extract_frm_json.ipynb -  Data Cleaning of json file and visualization of db
- uber_eats.db - database Created 

## How to Run
1. Install required libraries
2. Run:
   streamlit run Streamlit_vis.py
